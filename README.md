## Как выбирать редакцию

Явные поправки пользователя имеют приоритет над старым снимком. Более поздняя отправка документа сама по себе не доказывает его официальное вступление в силу. Разные варианты сохранены отдельно: не объединяйте их статьи и санкции. При расхождении называйте источник и уточняйте применимую редакцию.

В прежних военных уставах утрачена цветовая маркировка неподтверждённых изменений. Для УВС используйте обновлённую редакцию пользователя 1de26134; старый текст и снимок сайта сохранены для сравнения. ПГО 9.9: **48 часов** по поправке пользователя. Лимит нападения на Форт: пользователь указал **80**, общий исходный текст содержит **50**; решение администрации отдельно не проверено. Подробности — в файле поправок.

Оформление добавляет заголовки и навигацию, сохраняя формулировки норм. Оригиналы вложений сохранены побайтно. Изображения и карты, отсутствовавшие во вложениях, не восстановлены. Автоматического обновления с форума нет.
