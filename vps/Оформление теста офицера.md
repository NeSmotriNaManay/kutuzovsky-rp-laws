## Инструкция к тесту — текст для вставки

Перед началом укажите своё игровое имя и фамилию, постоянный статический ID персонажа, Discord ID и код попытки, полученный от инструктора. Проверьте данные: результат должен относиться именно к вам.

• В тесте 15 вопросов. В каждом — один правильный ответ.
• Время прохождения — 15 минут.
• Для сдачи нужно правильно ответить минимум на 12 вопросов из 15 (80%).
• Вопросы выбираются из учебного банка; порядок вопросов и вариантов ответов перемешивается.
• Проходите тест самостоятельно: без подсказок, поиска ответов, использования ИИ и помощи других игроков.
• Запрещено указывать чужие данные и сдавать тест за другого участника.
• Начинайте попытку после согласования с инструктором.

После завершения отправьте скриншот результата в канал проверки ВПС в Discord. Инструктор сверит данные и результат с записью на сайте.

Успешный онлайн-тест — первый этап аттестации. Далее необходимо разобрать с инструктором две устные ситуации и подтвердить работоспособность видеофиксации: реальный откат с изображением игры и звуком, включённая игровая бодикамера с красным индикатором.

При техническом сбое сообщите инструктору. Повторная попытка после несдачи — не ранее чем через 24 часа. Сдача теста сама по себе не присваивает звание и не расширяет полномочия.

## Форма регистрации

Все поля обязательные. Текстовый ввод для идентификаторов сохраняет длинный Discord ID без округления.

| Поле | Тип | Подсказка |
|---|---|---|
| Игровое имя и фамилия | Текст | Как указано у персонажа |
| Статический ID персонажа | Текст | Постоянный ID, не временный номер над головой |
| Discord ID | Текст | Числовой ID учётной записи, не отображаемое имя |
| Текущее звание | Текст | Звание на момент прохождения |
| Код попытки | Текст | Получите у инструктора перед началом |

Не запрашивать настоящие ФИО, телефон или адрес. Инструктор выдаёт код конкретному Discord-аккаунту и сверяет его с результатом. Самостоятельно введённый ID не подтверждает личность; повторно использованный или чужой код требует проверки.
