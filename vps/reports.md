# Discord — формы отчётов

Все формы заполняются от своего Discord-аккаунта. Инструктор связывает аккаунт со статиком в составе. Публичный GitHub содержит шаблоны, не личные записи.

## Наряд

```text
Имя персонажа / статик:
Тип: КПП / ПВ / город / дежурный / обход ВЧ / караул
Пост, ID смены, назначивший:
Начало — конец (МСК):
Полных нарядов: __ × 60 мин / __ × 90 мин
Тариф и основание надбавки:
Зачёт службы / из них КПП:
Баллы:
Скриншоты начала, докладов, окончания:
Личная запись и таймкоды проверок/событий:
```

Для города добавить состав, старшего, законное основание задачи, ID каждого вызова, выполненную работу, сведения о передаче. У каждого свой отчёт, общий ID смены. Для обхода — список проверенных ПВ/КПП и нарушения. Для дежурного — проверки, обращения и передача смены.

## Дроп / МП / поставка

```text
Имя / статик:
ID, вид, дата и время события:
Моя роль и выполненная работа:
Подтверждение участия и начисления штаба:
Штаб: __ баллов
Доплата ВПС на дропе: max(0,50−штаб) = __
Итого (один зачёт): __
Личная запись / таймкоды:
```

Отсутствующее начисление штаба не заполнять нулём. Специальные низкие тарифы занятий — по регламенту. Проведение МП: добавить цель, участников, результат и наблюдателя, если он нужен.

## Допуск / профпригодность

```text
Имя / статик / Discord ID:
Вид проверки:
Код попытки от инструктора:
Ссылка и скрин результата:
Дата проверки отката / закрытая ссылка:
Практика: П1 __/5, П2 __/5, П3 __/5 (для профпригодности)
Инструктор и итог:
```

✅ уполномоченного инструктора — все этапы завершены. ❌ — ещё не допущен, с пояснением. Никто не подтверждает сам себя. Одна галочка от обычного участника прав не даёт. Результат сверяется в кабинете теста, не только по картинке. Бонус профпригодности включается с даты итогового зачёта.

## Повышение и реестр

```text
Имя / статик, текущий → новый ранг:
Баланс до / стоимость / остаток:
Полные часы службы после прошлого повышения:
Из них КПП:
Ссылки на принятые отчёты:
Требуемые экзамены и допуски:
Дата предыдущего повышения:
```

У проверяющего единый журнал: ID начисления, статик, дата, источник, интервал/ID события, баллы штаба, доплата, итог, служба, КПП, ссылка, проверивший. Списания на звание — отдельные записи. Исправление отражается новой записью с причиной, история не удаляется. Реакция подтверждает проверку, журнал хранит баланс.
